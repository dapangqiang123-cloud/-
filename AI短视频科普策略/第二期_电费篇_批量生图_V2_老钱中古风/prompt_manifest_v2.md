# 第二期《中央空调电费篇》V2 老钱中古风视觉清单

## 交付结构

- `material/`：24 张纯素材图，不叠加标题、数据卡、图表或后期 UI。
- `effect/`：24 张对应效果图，仅使用中文标题与中文界面信息。
- `ui_png/`：24 张与效果图一一对应的 2160×3840 透明 PNG，可直接用于后期叠加。
- 三套文件均按 8 镜 × 3 版组织；效果图与透明 UI 使用相同编号。
- 旧版目录未覆盖，V2 独立保存。

## 统一视觉标准

- 家具与空间：参考用户提供的中古住宅图片，使用胡桃木、奶油色灰泥、洞石、皮革、藤编、纹理玻璃、开放书架、收藏级中古单椅、低饱和橄榄绿与深蓝点缀；避免普通奶油风样板间。
- 人物：高净值中国家庭的自然生活状态；真实皮肤、面部轻微不对称、碎发、自然手部与松弛姿态；不看镜头、不摆拍。
- 穿搭：夏季老钱风；细针织短袖 Polo、亚麻短袖衬衫、短袖针织上衣、高腰阔腿裤、过膝长裙、低调皮鞋和简洁皮具；不使用卫衣、厚针织、夹克或长袖秋冬装。
- 空调：室内仅使用超长窄幅连续水平百叶风口；室外机和线控器使用璀璨官方资产合成。
- 文字：效果层不使用英文界面；`C3D` 为产品型号，产品上的 TRÉSOR 为官方品牌标识。
- 水印：生成底图统一裁除最下方边缘后再输出 9:16，避免参考网站角标进入成片。
