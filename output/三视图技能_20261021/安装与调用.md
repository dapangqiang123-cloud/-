# 三视图｜安装与调用

技能名：三视图。技术标识：`san-shi-tu`。版本：1.1.0，2026-10-21。

说“直接生成三视图”，就把五官、穿搭和版式在一次生成中完成，只交付一张“全身正面＋正面/45°/90°上半身特写”形象板。无需先生成母图，也不要求确认母图。已有清晰参考就沿用；没有参考就按角色设定设计同一个人。只有明确要求“先定脸”时才单独出母图。支持只写提示词、直接生图、同人换装；是否能生图取决于当前环境是否开放图像工具。

## Codex

本机技能已安装，更新时会同步到用户技能目录。可在新对话输入：

```text
使用 $san-shi-tu，直接生成三视图。
人物是【角色】，穿搭是【描述】，只输出形象板。
```

也可以说“调用三视图技能”。若新技能没有出现在选择器中，重新打开会话或重启 Codex 后再查看。

原始技能文件位于本文件旁的 `san-shi-tu/`，其中 `SKILL.md` 是主规则，`references/` 是可修改的提示词模板与家庭角色示例，`agents/openai.yaml` 负责显示名称。全部为文本，无代码执行依赖、密钥、账号连接或本机绝对路径。

## ChatGPT：Skills 安装包

文件：`三视图-ChatGPT安装包-v1.1.zip`；不带版本号的安装包也已同步为此版本。

1. 在 ChatGPT 打开 **Plugins（插件）→ Skills → Create → Upload from your computer**。
2. 选择安装包，按界面提示完成扫描、安装或启用。
3. 在对话中用 `@` 选择该技能，或直接说“使用三视图技能”。列表可能按技术标识显示为 `san-shi-tu`。

安装包为标准技能目录：单一顶层文件夹 `san-shi-tu/`，其中只有一个 `SKILL.md`，并带相对引用的支持文件。如果你的上传界面要求选目录，请先解压后选该目录；如果只有编辑器，可以使用下方完整文本版填写工作流。不要把外层交付文件夹误当成技能目录。

Skills 是否出现与账号、产品界面和工作区设置有关。OpenAI 当前帮助说明列出了符合条件的 Business、Enterprise、Healthcare、Edu 账号；不能保证任意个人账号都有此入口。本次已检查本地技能结构和压缩包完整性，未登录你的 ChatGPT 验证上传结果，也未替你在云端安装。

## 没有 Skills 入口：完整文本版

文件：`三视图-ChatGPT完整文本版.txt`。

在一个专门制作人物的 ChatGPT 对话中，粘贴该文件全文，并在末尾添加当前需求。它包含工作规则和模板，不依赖读取其他本地文件。仅上传文件时，再发一句：

```text
请把附件《三视图-ChatGPT完整文本版》作为本对话的人物制作工作规范。
这次需求是：【角色、服装、仅提示词或直接出图】。
```

文本版用于当前对话，不等于已安装成可在所有新对话自动调用的技能。原始人物和服装参考需要实际上传到正在使用的对话中。

## 常用调用

```text
调用三视图，直接生成三视图。人物是42岁女建筑师，沉静但有亲和力，穿石墨灰短外套和灰蓝内搭。
不要模特脸，只输出一张全身照＋三张上半身特写的合成形象板。
```

```text
调用三视图。上传图1是已定的人物，图2只参考服装。
保留图1的五官和发型，直接生成全身正面＋正面、45°、90°上半身特写的一张形象板。
```

```text
调用三视图。同一位奶奶做户外登山和室内休闲两套穿搭，每套一张板。
如有清晰身份参考则沿用；没有时先直接出第一套形象板，第二套使用第一套的清晰身份，不额外出母图。
```

```text
调用三视图。检查这张图为什么AI感重，先分析光线、骨相、表情和材质。
这次只给原因和整合后的重做提示词，不生成。
```

## 可改范围

每次主要改角色、3—4个五官记忆点、发型体型、穿搭和输出方式。已有母图无需重复写五官设定。家居品牌、爷爷72岁/奶奶69岁/女孩6岁等仅为示例，可全部替换。

板式是当前工作流的默认选择，不是经跨模型实验验证的通用最优方案。若项目明确需要全身正侧背，直接提出即可。真实感与身份一致性仍需看实际输出；“真实皮肤”“RAW”“8K”等词不构成质量保证。
