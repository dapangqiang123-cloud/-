## 样张交付与检查

三张最终文件均为原始 **1254 × 1254 PNG**。提示词中提出了优先2048方图的意图，但工具实际交付尺寸为1254方图；本次未放大、未锐化、未二次调色。三张单独从文字生成，无连续编辑导致的退化。

- **树下听秋**：树干框景、侧向光、暖肤与浅色衣料成立；眼睛、碎发和握扇手清楚。 与参考差异：比参考片明亮，发饰与衣领较精致，光偏侧逆光。若继续贴近，应减少背景亮斑和装饰，让暖光更集中地落在脸上。
- **窗边读信**：窗框位置、侧脸视线、粗麻经纬、旧木和手持纸张关系稳定。 与参考差异：更接近柔和自然光，参考片部分镜头的暖肤和暗部对比更强；后续可在保持清晰度时，收低室内补光。
- **雨后檐下送别**：双人视线、酒杯与桌面的关系可读，马和柳树形成纵深，屋檐木结构与湿路成立。 与参考差异：衣料磨损偏重、地面更湿，背景略亮；更贴近参考时可减少破边和积水，让暗绿占比增加。

三个样张说明可以建立接近的视觉体系，但尚不等于严格1:1；若用于正式系列，应选定一张作为色彩与光线基准，再结合清晰人物、场景和产品参考校准连续分镜。


以下是依据原生抖音 App 中可见作品拆解的复现提示词，不是作者原始提示词。本轮每张从文字独立生成，没有使用模糊截图或退化结果作底图。

## 可复用的风格母版

把【】内信息换成自己的故事；同一支片固定色彩与光线逻辑。

> 生成一张【画幅】的真实中国古代生活电影剧照。场景是【具体空间、季节、时段】，人物【年龄、服饰、一个小动作、视线对象】。采用自然主义表演，不看镜头。画面以前景【门框／树干／帘／他人肩背】组织空间，人物在【画面位置】，背景留出【低信息区域】。主光来自【明确方位与实际光源】，照亮【脸／手／道具】，另一侧保留柔和深影。深墨绿、灰青、炭褐、旧米白构成低饱和主色，皮肤温暖自然。真实毛孔、细纹、碎发、粗麻经纬、旧木磨损和接触阴影。眼睛、手指、主要道具与关键建筑结构清楚；仅远处背景自然柔化。使用【35mm环境／50mm中景／85mm近景】的视觉空间感。没有美颜磨皮、夸张妆容、塑料皮肤、仙侠雾气、强烈青橙滤镜、过度锐化、HDR、文字、水印或边框。

焦距与光比是控制外观的提示，不是作者的真实参数。每张只选择所需的一个景别。

## 分镜模块

将其中一条接在母版后面，可扩展成一支片：

| 镜头功能 | 可直接使用的描述 |
| --- | --- |
| 环境建立 | 平视或稍低机位，湿石路与朴素生活器物位于前景，人物尚未进入或只占小部分，旧木与墙体结构清楚，环境光说明时段。 |
| 人物关系 | 双人中景，两人处于相同空间并有明确视线交流，服装颜色形成轻微区分，人物之间放一件有叙事作用的物件，前中后层次自然。 |
| 单人动作 | 半身中景，人物只做一个小动作：展开信纸、抬起杯子、整理衣角或停下脚步；动作对象可见，手势准确。 |
| 面部反应 | 胸部以上近景，人物看向画外对方，表情微小而可读，皮肤有自然年龄纹理，单侧柔光，背景颜色与上一镜一致。 |
| 道具插入 | 手与衣缝／杯沿／书页的近距离特写，材质、握持和接触关系清楚，不出现无意义装饰，背景仅保留同场景的色彩。 |
| 环境收束 | 人物在门框或屋檐中回望／离去，距离与之前不同，保留一块安静区域供后期排诗，光源与建筑连续。 |
