## 六篇拉片记录

### 1. 《寻隐者不遇》：先看人，再让动作指向空间

| 约时点 | 实际观察 | 可复用规律 |
| --- | --- | --- |
| 0–1秒 | 孩子坐在松树下，低头用双手整理草药；竹篮靠近下方 | 手上已有具体任务，人物不会为镜头空摆姿势 |
| 4秒 | 宽景：孩子在左下，来客在右，树干与上方松枝框住山林 | 人物高度差、距离与朝向先把关系讲清楚 |
| 6–7秒 | 来客背肩占右侧大块虚焦前景；孩子清晰，看向来客 | 过肩构图让观众置身对话中，前景不挡眼睛 |
| 8–10秒，连续 | 孩子抬起手臂，肘部先弯后伸，手指指向右上；视线回到来客，短暂保留指向 | 动作有起点、路径与终点；另一只手与坐姿基本稳定 |
| 中段 | 切入云雾山景；缓冲导致该切点无法精确定位 | 被指向的空间可以用单独镜头回应 |
| 约14秒 | 来客面部近景，向左下看，眉间略收，嘴微张 | 接受信息的人需要自己的反应镜头 |
| 约20秒 | 回到宽景，孩子继续低头整理，来客望向山间 | 结束后回到生活状态，而非持续做动作 |

画面基底是橄榄绿、石灰灰、木褐、暖米白；温暖皮肤处于深绿包围中。自然侧上方光有明暗分区，未把整张脸均匀照亮。所抽样的问答近景基本稳定，没有证据支持大幅环绕或升降运镜。

### 2. 《回乡偶书》：好奇问话与温柔回应

| 约时点 | 实际观察 | 可复用规律 |
| --- | --- | --- |
| 3秒 | 老人持杖，树与天空建立外景；褐色衣袍、白发形成材质差异 | 角色年龄与体态直接参与叙事 |
| 8–10秒，连续 | 孩子向左上仰视，嘴打开说话再收住，头部只有小幅抬动 | 眼神先落到对象，再说一句话，不反复点头摇头 |
| 约11秒 | 硬切老人面部，目光向下，眼角收起，微笑较轻 | 用对方反应完成一句问话的意义 |
| 15–16秒 | 老人侧面大近景，白发、眼周细纹清楚；浅暖天空留白 | 年龄感来自结构和纹理，不需要夸张锐化 |
| 约23秒 | 老人大块前景在左，两个孩子在右仰头；树干分隔空间 | 用高度阶梯与视线建立自然构图 |

色彩更偏金色傍晚与灰褐、草绿。边缘光只在发丝、局部轮廓出现，脸仍有柔和环境补光。墙面破损与粗旧衣物属于故事生活条件，不纳入品牌风格母版。

### 3. 《重阳簪菊》：自然感来自朋友之间的反应

| 约时点 | 实际观察 | 可复用规律 |
| --- | --- | --- |
| 开场 | 多位女子位于画面下部，远山占较大上方空间，松枝在边缘 | 人小景大用于建立诗意尺度，不让每一镜都是大头 |
| 约6秒 | 朋友伸手到主角发髻上方整理浅黄菊花，其他同伴分散在后景 | 手的动作有明确接触对象，后景人物有关注目标 |
| 约12秒 | 换角度看朋友说话和微笑，主角背侧在左 | 对话用角度变化接续，不必强迫单镜旋转绕人 |
| 17–19秒，连续 | 主角手从花边落下，低眼含笑，头部略低又轻轻回稳；后方同伴微笑与眨眼有差异 | 手势结束后，情绪仍保留；同伴不是同步微笑的人偶 |
| 24–25秒 | 回到群像与山景，衣袖、发丝有轻微变化 | 表演收束后留出环境呼吸 |

关键近景有三层：右侧失焦肩背／中景主角脸和菊花／后景两位同伴。主角黑发与浅黄花、灰蓝衣料、暗绿松林互相衬托。肤色柔和，亮部平滑过渡；不应把平台压缩造成的软当作糊脸指令。此段机位基本固定，细微画面漂移不足以证明推轨。

### 4. 《渔家傲》：动作带着情绪变化

| 约时点 | 实际观察 | 可复用规律 |
| --- | --- | --- |
| 开头0–3秒，连续抽看 | 面部极近景，头侧倚，眼睛逐渐张开；荷叶在左，局部暖光照额头、鼻梁和脸颊，细发与少量汗珠可见 | 局部光与皮肤细节建立身体感；苏醒不等于突然瞪眼 |
| 约6秒 | 舟内两位女子回头或侧看，前后位置略错开 | 用视线共同指向画外事物 |
| 12–14秒，连续 | 灰衣女子双手调整握持，把斜放的木篙抬到较直立位置；宽袖随前臂落下，身体小幅配合 | 手臂、接触物、衣袖有连续的受力关系 |
| 15–16秒，连续 | 她持篙停住，眉间收紧，嘴唇轻抿，侧看同伴；随后切船头搁在沙滩的细节 | 困惑来自动作受阻，插入物件镜头说明原因 |
| 约18秒 | 三人同框，左右错开，互相侧看；持篙者在右 | 让旁人注意到主角的状态，形成反应链 |
| 24–25秒 | 三人都笑了，但有含笑、低眼、露齿的差异；前下方荷叶虚焦 | 同一情绪也要保留个体差别 |

这是六篇里较明显的暖肤与冷青绿水面组合，暖色倒影在水中局部出现；并非全画面统一橙色滤镜。持篙近景的背景关系较稳定，主要运动来自人、篙与水。不要把它改写成快速船体追踪或大幅手持晃动。

### 5. 《小儿垂钓》：专注、打断、回归，以及一次移焦

| 约时点 | 实际观察 | 可复用规律 |
| --- | --- | --- |
| 开头至约3秒 | 孩子坐左下持竿看水，成人右侧弯腰靠近问话，斜线钓竿穿过画面 | 坐与站的高度、前倾体态让关系明确 |
| 约4秒 | 孩子空出的手在胸前抬起，嘴收成嘘声口型；另一手仍抓竿 | 在原任务不丢失的情况下做一个小制止动作 |
| 5–6秒，连续 | 切成人近景；他眼睛侧移、眉头变化，接着朝孩子方向靠近 | 对方先反应，再调整身体，不把一切同时发生 |
| 7–8秒，连续 | 两人近景，孩子从成人方向把脸和视线转回水面；成人仍看着他 | 同一镜中两人的关注点可以不同 |
| 8–9秒，连续 | 孩子的脸先清楚，随后虚化；前方竿尖成为清楚的视觉重点 | 一次由脸到近处竿尖的焦点转移，把注意力交回垂钓 |
| 约13秒 | 双人中景重新交代孩子持竿、成人弯腰看水的关系 | 细节后用关系镜头重新定位 |
| 约21秒 | 两人侧面朝向水面，左侧水面形成留白，诗句进入 | 共同沉静作为结尾状态 |

绿色比《长干行》更丰富，但压住鲜艳度；人物脸的亮度高于周围衣物与草丛。这里的移焦可以迁移到人物与茶器、花枝或产品细节之间。若是产品卖点镜头，则不能为了氛围把需要辨认的标识、按钮或面板长期虚掉。

### 6. 《长干行》童年版：先有共同的小事，才有表情

| 约时点 | 实际观察 | 可复用规律 |
| --- | --- | --- |
| 开头至约6秒 | 女孩蹲坐在篮前摆弄青梅，随后向右上看；脸周围碎发自然 | 有手部任务，也有来自画外的关注触发 |
| 约12秒 | 近看竹篮、青梅与手，女孩一手扶篮，一手接触果子 | 器物特写把人物关系落到可触摸的东西上 |
| 16–17秒，连续 | 男孩持竹竿经过前景，转向女孩并停住；女孩端篮站在后方 | 走过、减速、停下，动静有转换 |
| 约18秒 | 男孩拿着青梅低头看，女孩背侧虚焦在前 | 接触小物后先消化当下感受 |

## 共同视觉语言：保留什么，如何写进提示词

| 维度 | 六篇的共同倾向 | 可执行描述 |
| --- | --- | --- |
| 画风 | 接近真人生活电影片段，带诗意，不是水墨画或仙侠插画 | 真人电影静帧，可信的脸部结构与身体比例，抓取事件中的瞬间 |
| 人物 | 年龄、脸型与神情有差别；关注对方或手上物件 | 人物不看镜头，明确看向谁／什么；淡妆、自然肤色，保留细纹、发丝与局部肤理 |
| 光 | 有方向的自然光与较软环境补光并存 | 暖侧光局部落在脸颊与手背，背光侧仍有结构；光源方向固定，高光渐缓 |
| 色 | 暖肤、米白、灰褐对深绿／灰绿；部分篇章偏灰蓝 | 深橄榄绿或灰青为环境主色，温暖皮肤作为视觉落点，少量奶油黄与旧蓝；避免通篇黄蒙蒙 |
| 质感 | 哑光材料，布料有重量，头发有层次；面部不是塑料 | 细织物纹理与自然褶皱、柔和皮肤反光、清楚眼睛；避免蜡皮、磨皮、夸张毛孔锐化 |
| 构图 | 关系构图、前景遮挡、侧脸与过肩、不对称留白 | 前景失焦肩背或枝叶／清晰主角／较暗后景；视线方向有空间，主角脸不被挡 |
| 景别 | 人物近景与关系中景、环境宽景、器物细节交替 | 一段只承担一个叙事功能：看环境、看动作、看反应或看原因 |
| 氛围 | 有具体生活活动、安静但不僵住 | 让人物在被观察时仍做自己的事；微风只影响少量发丝、袖缘与枝叶 |

六篇共同的“柔”应通过亮部过渡、光线、色彩与景深实现，不通过抹掉五官、手指或建筑结构实现。平台压缩、运动模糊、AI局部错误都不列入风格目标。

## 璀璨适配：材质真实，空间考究

| 原片中出现的元素 | 璀璨适配规则 |
| --- | --- |
| 斑驳脱皮墙、杂乱古宅、破旧门窗 | 平整温润的浅米灰墙、维护良好的深色木格窗、整洁园林庭院；建筑节点合理清晰 |
| 粗布破边、脏污、补丁 | 干净完整的细麻、棉麻、哑光真丝，剪裁克制，保留织理与自然褶皱 |
| 古朴器物 | 数量少、比例合理、做工精细的陶瓷、木器与石材，无需堆满装饰 |
| 自然草木与水面 | 修剪有度的庭院植物、清洁水庭、自然山水背景；不必全部变成室内 |
| 生活中的表情 | 保留专注、好奇、含笑、短暂困惑和朋友互动，不统一成端庄摆拍 |

品牌高端感从材质、维护状态、空间比例、陈设取舍中获得。不要靠大面积金色、宫殿、过亮灯带或光滑塑料表面补偿。

## 生图母模板与六种分镜模块

以下为新编模板。每次选一个场景、一个动作瞬间、一套光色，不把六篇的所有元素放在同一张图。

```text
生成一张[画幅]真人电影静帧，东方日常生活的诗意瞬间。
[角色年龄、长相区别、发型、完整清洁的服装]正在[具体生活任务]，这一帧是[动作的哪个阶段]。人物看向[明确对象与方向]，表情为[眼睛、眉毛、嘴角的具体状态]，不看镜头。
[景别]，镜头与人物[相对高度、角度]；[主角位置与占比]，留出[视线方向的空间]；[前景遮挡]、清晰主体、[背景]形成有依据的纵深。人物五官、与物件接触的手指保持清楚。
[来自画外某方向的自然侧光或柔和天光]，脸部明暗有结构，阴影有柔和环境反射，高光平滑过渡；[深橄榄绿／灰绿／灰蓝]环境与自然暖肤、米白衣料形成克制色彩关系。黑位有层次，色彩沉静但不灰脏。
皮肤有自然细微纹理与柔和光泽，眼睛清楚，发丝疏密真实；衣料有重量、织理和自然褶皱。背景可有适度景深，不能全画面发糊。
场景为维护良好、整洁考究的东方[园林／水庭／茶室／临窗起居空间]，细腻木材、哑光石材、完整墙面与少量精制器物，建筑结构合理。
画面无文字、水印、App界面。避免磨皮蜡脸、网红滤镜、夸张锐化、通篇橙黄、荧光绿色、塑料衣料、破败装修、脏污破衣、堆砌宫殿装饰。
```

## 视频提示词母模板

自然感的核心是：先有触发，视线找到对象，再产生表情与动作，最后停住或回归原任务。不要机械地要求每镜都按完全相同的眼神顺序；只写当下事件有因果的变化。

```text
以输入图为首帧，生成[时长]秒的单一连续镜头，保持角色身份、人数、服装、空间布局和光源方向。
机位：[人物眼平／略低／过肩]，[中近景／近景]，[固定机位，或只选一种缓慢移动]；保持原有画面轴线与视线方向，主角面部清楚，背景层次稳定。
初始状态：[人物身体姿态、两只手各在做什么、眼睛看哪里]。
触发：[画外同伴的一句话／对方递来的物件／任务中的小变化]。
动作发展：[视线的明确落点] → [小幅眉眼嘴角变化] → [单一手部动作，写清接触点、路径、受力] → [身体与衣料的少量跟随]。
收束：[完成后停留／轻轻移开视线／回到原任务]，保留自然呼吸和偶发眨眼，不重复表演。
环境：[轻微风动、少量发丝袖缘、稳定自然水纹]，亮度与阴影连续。
约束：不看镜头，不持续摆头点头，不反复眨眼，不把小笑突然变成大笑；手与物件接触稳定，五官、人数、器物不漂移。除非明确指定移焦，焦点保持在人物眼睛；不增加快速环绕、突然变焦或无因镜头晃动。
声音：[如工具支持，写所需的简短现场声与准确对白；无对白则写自然闭口，不自行口型说话]。
```

模板时序是生成起点，不保证工具逐秒执行。实际成片若出现动作拥挤，减少事件数或拆镜；不靠延长无目的摆动填时长。

## 六个可直接替换场景的视频动作模板

### A. 寻隐：抬眼回应与指向，建议5秒

```text
固定过肩中近景，主角坐在左侧，来客右侧肩背虚焦。首秒主角低头整理案前枝叶，左手轻按枝叶，右手空出。听到右前方来客询问，主角先抬眼看向对方，再把右肘轻抬、前臂向画外右上方伸出，食指指向庭院深处；动作从容，不抬高肩膀。指向完成后，视线回到来客脸上并短暂停住，左手与坐姿稳定。暖光与树影保持连续，摄影机固定，不增加环绕。
```

要看指向的空间，另生成一个庭院／山水镜头再剪入，不要求此镜突然飞向远方。

### B. 回乡：倾听、仰视与微笑回应，建议分别生成两个4秒镜头

```text
镜头一：固定略低机位的中近景。人物先认真看着画外左上方的对话者，眼睛稍微睁开，轻抬下巴，嘴唇短暂张开问一句[准确对白]，说完自然合拢，等待回应。肩膀放松，不反复仰头，不做多余手势。
镜头二：固定老人面部近景。老人向画外右下方看，听完后停一小会儿，眼角轻收、嘴角略抬，轻轻呼气，笑意留住，不夸张露齿，不连续点头。侧光照出眼周细纹与白发，阴影有柔和填充。
```

剪辑保持彼此视线相对。静帧统一角色外观和轴线后再做两个镜头。

### C. 簪菊：被朋友整理花饰后的含笑，建议5秒

```text
固定近景，女主清晰位于左中，右前景同伴肩背柔焦，后方两位朋友位置不变。首帧女主右手在发间浅黄菊花旁轻扶，确认花饰已稳后缓缓收手到胸前，再自然垂下；手掌不穿过头发或花瓣。她低下眼睛，嘴角浮起很浅的闭口笑，随后略抬眼看向右前方朋友，头部只轻微调整。后方朋友一人微笑，一人安静看着，反应不同步。少量碎发轻动，光斑稳定，摄影机不绕行。
```

若需要朋友实际插花，把“插入并固定”单独做一镜，避免同一短镜同时处理多手接触、说话和复杂运镜。

### D. 渔家：器物动作受阻后的侧看，建议5秒

```text
固定中近景。人物双手握住[已在首帧明确的器物]，先看接触位置，以自然速度完成一次[抬起／放下／轻推]；动作遇到轻微阻力后停住，两手仍握牢器物。她的眉间轻收，嘴唇略抿，眼睛先向画外左侧同伴移去，头随后小幅侧转，带一点困惑，停留等待对方回应。衣袖跟随手臂下落，器物形状和接触点不变，背景水纹轻微，不增加摄影机晃动。
```

仅在叙事确有小阻碍时使用；品牌日常可以改成“察觉同伴的小玩笑后侧看”，不必把产品本身写成故障或难用。

### E. 垂钓：专注中的小制止；另设移焦镜头

```text
动作镜头，4秒：固定双人中近景。主角仍专注看着前方[安静活动]，一只手稳定持物。听到旁边朋友说话后，空出的手轻抬到胸前，掌心朝向朋友做一次小幅示意，嘴唇轻收作简短嘘声，然后手慢慢落回原处，目光重新回到任务。朋友停止说话，稍微俯身顺着主角的视线看去。动作只做一次，不持续挥手。
移焦镜头，3–4秒：固定近景，人物脸位于中景，近处[花枝尖端／茶器边缘]已在构图中。开头焦点在人物眼睛；人物把目光移向器物后，焦点平滑移到该器物，脸退入柔焦，焦点抵达后保持。没有变焦、没有镜头前进、没有第二次来回移焦。
```

移焦是独立可选手法，不能默认用于每一镜。产品需要可读标识时，以标识和结构清楚为优先。

### F. 长干：拿到小物后的偷看与低眼，建议4–5秒

```text
固定过肩近景，主角在右，另一人的背侧与肩膀在左前景柔焦。主角手中已拿着一枚青果，先低头看果子，用手指轻轻转动一点；随后只抬起眼睛看向左前方同伴，嘴角带很浅的闭口笑。对视短暂停留后，他把目光轻轻降回果子，笑意保留，头部不大幅摆动。对方前景只做细微自然动作。采用柔和中性天光与旧蓝、米白、淡绿配色，没有强烈金色轮廓光。
```

品牌场景可以替换为接过茶杯、分享时令水果、看朋友整理花枝。关键是物件带来情绪，不能只写“唯美微笑、自然动作”。

## 运镜选择与剪辑使用规则

1. **固定镜头为基础。** 六篇关键人物段落多靠眼神、嘴部、手与道具的变化成立。未确认的细微漂移不写成推轨实证。
2. **确定观察到的移焦单独保留。** 《小儿垂钓》脸到竿尖可转化为一个明确的注意力转移。单次移焦比整段反复拉焦更贴近这次观察。
3. **轻推、轻移作为新制作选项，而非作者全片事实。** 如要强调表情，可选择4–5秒内很小幅度的缓慢前移，保持头部留量，不改变视角或绕过人物；同一镜不再叠加横移、环绕、升降。
4. **景别变化由剪辑承担。** 关系中景 → 接触物件细节 → 人物反应近景 → 环境／共同状态。每次切换都回答一个新的信息。
5. **动作有休止。** 完成接触、指向或回应后保留短暂停顿，或回到原任务。背景人物不同时摆头、眨眼和微笑。
6. **声画分开核验。** 对白须有准确文字且符合生成工具支持；本次只凭视觉与字幕观察，不把无音频分析的印象写成声音事实。

## 后续样片验收

- 人物：五官与身份不漂移，眼神方向明确，表情幅度小而有因果，动作完成后停住。
- 接触：两只手职责清楚，物件不穿透、不变形，衣袖有重量，移动不悬浮。
- 摄影：焦点服务当前信息，前景虚焦不挡脸；空间轴线、光源方向与曝光稳定。
- 光色：暖肤不橙，绿不荧光，阴影不灰脏，局部高光有过渡；《长干行》式柔光与傍晚式暖光分开选。
- 品牌：墙面门窗完整、陈设精简、服装整洁，有真实触感与生活使用痕迹但不破败。
- 清晰度：产品轮廓、标识、按钮以及需要辨认的脸与关键建筑结构清楚。退化图不再编辑，回原始清楚资产重生；不以锐化或放大代替。
