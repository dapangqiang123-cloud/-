## 结论先读

**这套风格可以用 GPT Image 2.5 尝试复现，重点在“真实生活电影的光线与表演”，而不是堆叠古风装饰。** 最值得借鉴的是：墨绿／灰褐的深暗背景、温暖但自然的皮肤、可触摸的旧材料、侧面自然光、人物微表情，以及由物件和视线连接起来的分镜。

**作者的具体生图模型尚未证实。** 作品反复带有“即梦ai创作者成长计划”等标签，属于即梦生态的使用／参与线索；标签不能证明全部静帧由即梦生成，更不能证明 Seedream 的某个具体版本。查阅主页、作品说明、部分评论以及公开检索，未找到可核验的作者模型披露。图像外观也不足以鉴定模型。

本次提示词是根据可见画面反向拆解后编写的复现方案，**不是作者泄露或公开的原始提示词**。可以追求很接近的视觉语言，不能保证无参考图的一次生图就达到严格的1:1。

## 关键拉片

### 《送元二使安西》：最适合学习完整叙事

| 抽样位置 | 可见画面与景别 | 画面如何成立 | 可迁移的分镜方法 |
| --- | --- | --- | --- |
| 约01秒 | 低机位环境细节，马与木桶、雨后石路 | 湿石路占较大前景，灰绿环境与旧木建立现实感 | 先用一个能说明时间、地点与出发意图的物件镜头开场 |
| 约04秒 | 屋檐下两位男子隔桌对坐，马在后方 | 上方暗屋檐框景，人物与马形成前中后层次；淡青酒器很克制 | 双人中景先交代座位与视线方向 |
| 约08秒 | 青灰衣男子扶酒壶的中近景 | 温暖侧光照脸，灰青粗麻与深绿背景形成分离 | 行为镜头推进关系，不必每镜都换大场景 |
| 约16秒 | 戴黑布帽男子面部近景 | 皮肤纹理、眼角细纹、胡茬可见，神情收着，明暗方向稳定 | 用反应近景接住对方的动作与话语 |
| 约20秒 | 男子举青瓷小杯 | 杯、手、眼睛成为重点，动作小，情绪具体 | 给关键道具一个可辨识的动作落点 |
| 约25秒 | 檐下主人背侧在前，行者回望，马在右侧 | 从桌边亲近关系回到空间距离，竖排诗句进入画面空位 | 结尾让人物关系转成空间关系，再落诗 |

**叙事骨架：环境预告 → 人物关系 → 具体动作 → 情绪反应 → 离别空间。**
这比六张相同景别的漂亮人像更适合持续制作系列。

### 《九月九日忆山东兄弟》：窗光与秋色

约03秒：人物位于右侧，窗在左，灰绿袍、褐色头巾，书页在下方；窗外是低饱和的暖秋色。亮部集中在面部与书页，木结构围出安静空间。

约16秒：头戴赭褐布巾、簪绿色枝条的男子露出笑容，旁边有人物进入；深叶色背景衬托暖肤色，动作与表情带来生活气。

约32秒：书生在窗边的环境侧面构图，近处深木框与远处浅色屋顶、秋色形成层次，诗句进入空位。

可转成提示词：**侧窗自然光、灰青粗麻、褐色布巾、旧木框景、窗外赭黄失焦树叶、克制的思念、侧脸近景。**

### 《初秋行圃》：最鲜明的人像光色样本

仅确认约02秒的清楚画面：树干占左侧，执团扇女子穿象牙白外衫、旧桃色内搭，后方有同伴；暖光从侧面照亮脸和部分衣袖，后景深绿。枝干参与构图，人物正被一个画外事件吸引。

最值得复现的是 **“暗树与深绿背景 + 一小片准确落在脸上的暖光 + 真实浅色布料”**。中段因缓冲没有形成有效样本，未补写不存在的镜头。

## 风格拆解与可执行设置

以下镜头焦距、光比和配色是**为复现而建议的控制语言**，不是作者工程参数或相机元数据。

| 维度 | 画面中反复出现的特点 | 写进提示词的方式 |
| --- | --- | --- |
| 媒介 | 古装生活电影的真实感 | 真实摄影、自然主义电影剧照、生活中的瞬间 |
| 主色 | 深墨绿、灰青、炭褐、旧米白 | 背景深绿偏暗；衣料灰青或亚麻白；皮肤温暖、不过橙 |
| 光 | 有来源的窗光、檐外天光、树隙日光、灯下暖光 | 明确光源方位、照亮范围、另一侧补光强弱 |
| 明暗 | 人脸被看见，大块背景安静 | 主体比背景亮约1—2档作为起点；暗部保留结构 |
| 皮肤 | 年龄差异、细纹、胡茬、碎发 | 真实毛孔与细小瑕疵、自然妆容、眼睛清楚 |
| 材料 | 粗麻、素绢、老木、灰墙、青瓷、湿石 | 写出经纬、磨损、重量、接触阴影，避免只写“高级质感” |
| 构图 | 树、门、窗、帘作前景，人物不总居中 | 前景遮挡＋中景人物＋低信息背景；看向画外 |
| 景深 | 人物明确，背景退后 | 双眼和手清晰，远处背景柔化；宽景保留建筑结构 |
| 景别 | 环境与中景建立关系，近景承接情绪，手部作插入 | 35mm环境、50mm人物中景、85mm面部、90mm细节作为视觉提示 |
| 表演 | 轻笑、停顿、低头、回望、举杯、握布 | 一镜只设一个具体小动作，说明动作对象与视线 |
| 字幕 | 标题书法、结尾竖诗、部分片段有对白中英字幕 | 先生成干净画面，在剪辑里统一排字和校字 |
| 画幅 | 所观察视频主体多为方形，主页封面另作裁切 | 首轮按1:1验证；若需9:16，重新构图，避免直接裁去手与道具 |

**最容易跑偏的词：** “仙气缭绕、唯美古风、梦幻光晕、绝美女子、极致通透、大片HDR”。这些泛词容易把真实生活感推成仙侠写真或过度磨皮的广告图。更有效的写法是明确“旧木窗左侧的柔光、灰青粗麻、右侧深暗室内、眼神落在手里的信上”。

## GPT Image 2.5 是否适合

官方文档已提供 GPT Image 2.5 的生成与编辑能力，并区分偏速度的 Flare 与偏高质量／精确编辑的 Sunburst。若使用可明确选模型的入口做正式视觉开发，可优先试 Sunburst；具体效果仍应以同一提示词和参考输入的实际比较为准。[OpenAI 图像生成文档](https://developers.openai.com/api/docs/guides/image-generation) · [官方提示词指南](https://developers.openai.com/api/docs/guides/image-prompting)

本研究的判断：

- **适合尝试：** 写实东方人物、皮肤与布料细节、有方向的自然光、低饱和调色、前景框景、生活化动作。
- **需要校准：** 全组人物身份、同场景光位、手与细小道具、衣饰年代细节、宽景建筑与马具结构。
- **不能仅凭模型保证：** 与原片逐像素一致、连续镜头每个细节不变，以及完整视频的表演与运动质量。静帧模型的结果不等于最终视频质感。

本轮三张使用本会话内置图像生成工具，从文字独立生成；工具接口未提供可核验的具体后端型号，因此这批图是视觉方向样张，**不标成已验证的某个 GPT Image 2.5 子型号跑分**。也没有把博主压缩视频截图或用户主页截图当作编辑底图。

## 提示词怎么复用

完整内容见同目录《02_风格提示词与三图生成记录.md》。推荐顺序：

1. 先固定画幅、媒介、肤质、材料与主色。
2. 每张只增加一个场景、一种核心动作、一组视线关系。
3. 指定主光来自哪里，以及什么东西必须清楚。
4. 为同一人物和空间建立经确认的清晰参考资产，再做连续分镜。
5. 后续如有面部、产品或场景退化，回到清晰原图，合并修改要求重新生成；不在退化图上循环修补，不用锐化替代重生。

用于璀璨生活方式内容时，可以保留这套侧光、材质和节制的表演，把场景换为现代东方住宅、茶席或庭院。若加入璀璨产品，必须另用清晰原始产品资产锁定轮廓、面板、标识和按钮；这三张纯风格样张不承担产品结构验证。
