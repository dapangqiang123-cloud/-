## 可编辑工程
根目录：`MixedMedia_空气翻墙_20261031/`

- `BRIEF.md` — 选题/VO/约束
- `engine/` — `index.html` + `timeline.js`（连续时间轴）+ `record.mjs`（Chrome 逐帧）
- `assets/official/` — 官方 Mini 切图、Logo（唯一产品来源）
- `assets/gen/` — Codex `image_gen` 拼贴主体（窗/墙剖/管/芯/气流/滤芯/台面/纸纹）
- `assets/audio/` — `vo*.mp3`、`mix20.m4a`
- `refs/` — 风格参考
- 重录：`cd engine && node record.mjs` → ffmpeg 拼静音 → 叠 `mix20.m4a`
