# 《空气怎么翻过墙》20s Mixed-Media 成片 Brief

## 选题
关窗也能换气：墙里藏着全热交换通道。以物件动作讲故事，不靠PPT字幕。

## 规格
- 时长：18–22s（目标20s）
- 画幅：1080×1920 竖屏 30fps
- 成片：有旁白 + 轻音乐 + 轻音效
- 交付：MP4成片 + 可编辑工程（HTML/Canvas或Remotion源码均可，禁止照搬已否的OpenFilm六镜模板）
- 工程根：本目录

## 禁止
- 山野/森林/枫叶/登山/户外营地元素（参考片里有户外道具，仅学手法，不学题材）
- Grok/xAI GenerateImage / GenerateVideo
- 重绘/变形官方产品外观；Logo只用官方原图
- 虚构风量、除菌率、内部精密结构；热交换仅作示意层叠
- 大标题+配图+箭头的PPT翻页；每几秒一张静态海报淡入淡出
- 复用 `Vox拼贴风格测试` / `Vox科普拼贴样片` 的布局与动画模板

## 风格（学参考手法）
参考：JP Morgan Payments Mixed Media Explainer（pegboard物件装配、纸片拼贴、真实摄影切片、手绘线、尺度跳切、连续转场）。
配色：米白 #F5F2ED / 暖咖 #433538 / 香槟金 #C4A574（可用橄榄 #6B6B47 作气流点缀）。
质感：纸底纤维、摄影抠像、手绘双线、真实物件阴影；高级克制，不要满屏粒子光效。

## 旁白（锁定，约20s）
1. 关着窗，空气怎么进出？
2. 墙里，藏着一条换气通道。
3. 两股气流交错，热量在芯里交换。
4. 脏的留下，干净的进来。
5. 璀璨 Mini 全热交换新风。

## 分镜（连续动作，非卡片翻页）
| 段 | 时码 | 画面动作 |
|----|------|----------|
| A | 0–3.5s | 米白纸底上，关着的窗框摄影切片落入；窗帘微动；手绘问号一笔勾出。文字极少或不加。 |
| B | 3.5–7.5s | 墙体截面像纸板被撕开/拉开；截面里露出纸质风道；尺度放大穿入墙内。 |
| C | 7.5–12s | 全热交换芯以层叠纸片/板片交错拼装（示意，非内部结构实拍）；进出两色气流纸条对穿交错。 |
| D | 12–16s | 气流纸条穿出墙另一侧；室内摄影切片亮起；滤层纸片落下拦住「脏」颗粒贴纸。 |
| E | 16–20s | 官方 Mini 原图（抠像）落到台面，轻接触阴影；官方Logo淡入；收版。 |

## 素材优先级
1. 官方：`assets/official/`（mini_*.png, logo_*）
2. 代码动画/矢量纸艺
3. ChatGPT 生图（经 Codex）仅用于：米白纸底纹理、室内窗框/墙截面摄影风切片、手绘线稿层、气流纸条——禁止生成产品机身与Logo
4. 即梦 Seedance 仅用于需要「场景自己活起来」的1–2个短镜头（图生视频），总积分 ceiling≤899；先 quote 再跑

## 技术路线（推荐）
- 主成片：自研连续时间轴 HTML Canvas / Playwright 录屏 或 Remotion（若可快速起项）；不要复制旧 OpenFilm scene.js 结构
- 音频：edge-tts 或系统TTS中文旁白 + 免版权轻BGM + 撕纸/落物轻SFX；混音进成片
- 即梦：`dreamina-canvas`，先 `auth status` / `model find`；每次生成前 quote，累计不超899
- Codex：`codex exec --sandbox workspace-write --skip-git-repo-check -C` 本目录

- 无山野；无产品变形；无文字横切；无转场蒙版露馅
- 成片路径：`交付/璀璨_空气怎么翻过墙_20秒_竖版.mp4`
- 工程可再编辑；写 `交付/制作说明.md`
