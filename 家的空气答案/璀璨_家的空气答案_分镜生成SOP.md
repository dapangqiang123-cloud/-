# 璀璨「家的空气答案」分镜生成 SOP

> 给谁用：Codex（拿到一份新脚本 xlsx，自动产出一份完整分镜规划表）
> 目的：脚本→分镜规划这一步标准化，不用每期从零想"这镜该拍什么风格"
> 输入：本期脚本 xlsx（镜号/时间/画面建议/VO口播/屏幕字幕）
> 输出：分镜规划表（见第6节字段结构）

---

## 0. 先说清楚问题出在哪，不然SOP会走偏

看完《层高篇》《能耗篇》两份脚本和能耗篇的16张分镜图后，先定位一个关键事实：

**分镜构思阶段其实一直不缺科普感。** 能耗篇的分镜里，电表悬浮卡、电费账单卡、"电费/能耗"圆圈分流图、APF对比柱状图、AI芯片可视化、用电趋势Dashboard——这几张信息密度和设计感都做到位了（对应图3/5/6/10/12/15）。

**问题大概率出在"图生视频"这一步，不是分镜构思这一步。** 圆圈分流图、对比柱状图这类矢量感强、文字精细的信息图，喂给即梦/可灵做图生视频时最容易糊字、线条抖动、版式变形——为了成片稳定，这类镜头在实际生产里往往被简化甚至换成"安全"的家居实景镜头。结果就是：科普感最强的那几张牌，没能活着进成片，最后剪出来的东西自然显得"就是几张家居图"。

**所以这份SOP的核心解法不是"再多让AI画几张数据图"，而是分层处理：**

> 数据可视化类镜头（圆圈图/柱状图/芯片图/Dashboard这种设计感强、文字多的）**不走图生视频**，直接交给Codex调用HyperFrames生成一段**透明通道（alpha）动效视频**：圆圈生长、数字跳动、描边动画、卡片弹入这类效果，代码层面做比图生视频稳得多、也比手动剪辑快。剪映里当一层透明素材直接叠加到背景上，不用关键帧手拼。这类内容清晰度和设计感的价值，全靠"稳"，宁可牺牲一点"呼吸感"也不能糊/变形。
>
> 只有实景类镜头（家居空间、产品运转、人物操作）才走 即梦/可灵 图生视频，因为这类内容本来就是靠运镜的"呼吸感"取胜，AI视频生成对它们也更稳。

这条分层规则是本SOP第1、2节的骨架，Codex 每次产出分镜规划表时都要先按这条规则给每一镜打"生成方式"标签。

## 1. 素材四分类与生成方式对照

| 类别 | 说明 | 生成方式 | 负责工具 |
|---|---|---|---|
| A. 官方产品素材 | 外机/内机/线控器等品牌自有图（真实拍摄或官方渲染），按产品系列分文件夹 | 直接使用，不二次AI生成；D2的"产品结构分解""技术线稿/蓝图"两种风格必须以此为底稿，不凭空造型；如需叠加数据高亮，走静态叠层 | `产品素材`文件夹（见下） |
| B. 达人实拍家居图 | 真实家居摄影，大宅/大平层/别墅 | 直接使用；局部修图（比如隐去杂物）由Codex任务内自动出图处理 | 达人素材 + Codex修图 |
| C. AI生成实景 | 客厅/卧室/玄关等生活方式场景，含镜头运动 | Codex任务内自动出首尾帧 → 即梦Seedance 2.0 Fast VIP 图生视频 | Codex（出图）+ 即梦（生视频） |
| D. HyperFrames透明通道动效 | 圆圈分流图、对比柱状图、AI芯片图、悬浮数据卡、Dashboard及更多科普风格（见2.1） | **不进即梦，也不走常规出图步骤**，由Codex调用HyperFrames生成带动效的透明通道（alpha）视频（数字跳动/描边/弹入/生长），剪映只做叠加合成 | Codex + HyperFrames（动效生成）+ 剪映（叠加） |

判断一个镜头该归 C 还是 D，看这条：**画面里如果超过30%面积是图表/图标/数字/几何线条这类"设计元素"，归D；如果主体是真实空间/人物/产品且信息以字幕条形式叠加，归C。**

## 2. 镜头类型库（7类）

每类给出：定义、视觉规范、生成方式（对应第1节的A/B/C/D）、参考镜头。

### Type-QA｜Q&A片头卡（固定模板）
- 定义：栏目统一开场，深咖背景+品牌角标+问题文字，每期只换问题文字
- 视觉规范：背景 `#3B2F2C`（深咖），金色细弧线描边，"璀璨中央空调 Q&A"小标题+金色分隔线+大字问题，字体思源宋体/Arial
- 生成方式：不进AI视频，纯静态模板，PS/剪映内直接改文字
- 参考镜头：能耗篇分镜图1

### Type-Hook｜痛点/悬念实景+字幕条
- 定义：开场2-4秒或过渡句，用一个有代入感的家居实景 + 底部大字字幕条抓住注意力
- 视觉规范：实景暖调，字幕条统一用"半透明深咖底+白字"或"纯白字+阴影"，不要用跳脱配色
- 生成方式：C类（AI实景，走即梦图生视频）
- 参考镜头：能耗篇图2（吊顶+"装中央空调"）、图4（"抛开本身设计方案的差异"）、图16收尾前那句

### Type-DataCard｜数据/悬浮卡片可视化（科普感核心，占比要保证）
- 定义：用设计感强的动效画面承载"结论/转折/数据"，是这个栏目"科普感"的主要来源
- 两个子类：
  - D1 实景叠加卡（电表读数、电费账单、温度设定异常提示）——真实场景+一张悬浮卡片，卡片本身由Codex调用HyperFrames生成透明通道动效，背景实景可以是C类AI视频，两层在剪映叠加
  - D2 独立科普镜头——整屏都是设计元素，纯D类，由Codex调用HyperFrames生成，往下细分6种风格打法（2.1节），生成前先过`科普感分镜素材参考`文件夹找感觉

#### 2.1 D2风格库（按脚本内容特征匹配，出分镜规划表时要标出用哪种）

目前能耗篇16张分镜里的数据卡清一色是"数据图表动效"这一种打法（圆圈图/柱状图/Dashboard），这也是"找的这种感觉不满意"的直接原因——招数太单一。往下这6种风格轮着用：

| 风格 | 视觉特征 | 适用的脚本内容 | 搜索/参考关键词 |
|---|---|---|---|
| 数据图表动效 | 圆圈分流图/对比柱状图/趋势Dashboard，数字为主视觉 | 出现具体数值、百分比、前后对比结论 | data visualization motion design、infographic animation |
| 产品结构分解 | 爆炸图/拆解动效，露出内部结构（压缩机/换热片/风道） | 讲"为什么/核心技术/内部构造"类原理性内容 | product exploded view animation、cutaway illustration |
| 技术线稿/蓝图 | 金色/白色线条在深色底上勾勒产品轮廓或空间平面图，工程感 | 讲精度/标准/数值范围类专业内容 | technical blueprint motion graphics、wireframe product |
| 场景创意演绎 | 超现实/艺术化手法表达抽象概念（如净化＝光粒子穿透空气） | 品牌理念、生活方式升华、情绪落点 | cinematic product reveal、concept visualization luxury |
| 材质工艺微距 | 金属拉丝/涂层/零件的微距质感 | 讲品质、耐用性、工艺细节 | macro material texture luxury product |
| 品牌图腾动效 | 天圆地方几何图形生长、LOGO粒子化 | 片头强调句、品牌背书、栏目转场 | geometric brand motion logo particle |

- 视觉规范：统一卡片语言——圆角矩形/圆形节点 + 金色`#B8952A`描边或图标 + 深咖/雾白`#F0EDE8`底色，数据数字用最大字号突出，避免小字堆砌；6种风格跨着用也要守住这套色板，否则又会散
- 生成方式：D类（Codex调用HyperFrames生成透明通道动效视频——数字跳动/描边动画/弹入/结构展开，剪映只做叠加，不进即梦、不走常规出图步骤）
- 输出规格：透明通道视频（ProRes 4444 或 WebM VP9 alpha），9:16 720×1280，帧率与正片一致，剪映直接拖入叠加轨道
- 参考镜头：能耗篇图3（电表卡）、图5（账单卡）、图6（圆圈分流图）、图7（温度设定卡）、图10（APF+AI横幅）、图12（AI芯片+柱状图）、图15（用电趋势Dashboard）——都是"数据图表动效"这一种风格，后续按2.1表往其余5种上扩

### Type-Product｜产品特写/参数展示
- 定义：官方产品图 + 关键参数数字高亮（APF值/厚度/金额等）
- 视觉规范：产品图用`产品素材`文件夹对应系列的官方实拍图（外机白色本体+香槟金圈，符合C3D色标），参数数字用D类卡片风格高亮叠加，不单独抠图硬贴
- 生成方式：A类（官方素材）+ D类叠层（参数高亮部分）
- 参考镜头：能耗篇图11（C3D外机+APF4.4）、图13（外机+"一年劲省594元"）

### Type-UI｜App/线控界面演示
- 定义：手机App或线控面板界面，展示AI省电模式、用电趋势等交互功能
- 视觉规范：界面截图/AI渲染需保持真实UI比例，不做失真夸张动效；人物操作手部特写要检查手指数量/动作合理性（AI视频最容易出错的地方）
- 生成方式：真实界面截图直接用（不生成）；如需人物操作过程，走C类AI视频但要重点复检手部
- 参考镜头：能耗篇图9（墙面线控实拍）、图14（AI图标+App遥控）、图15（女子沙发+手机Dashboard，兼具UI与DataCard属性）

### Type-Lifestyle｜家居生活方式实景
- 定义：大宅/大平层/别墅内景，产品隐形出现（出风口可见但不抢戏），红书高级感构图，用于氛围过渡、情绪收束
- 视觉规范：暖调自然光，留白构图，出风口只用隐藏式横向线性长条风口（禁用外露风口/独立基座），符合品牌"高端克制"调性
- 风格参考：生成前先过`家居素材风格参考`文件夹抓气质（光线/构图/留白/色调），**不照抄具体家具款式、软装搭配或装修细节**（避免版权风险），Type-Hook用到家居实景时同样适用这条
- 生成方式：B类（达人实拍优先）或C类（AI生成，走即梦）
- 参考镜头：层高篇"大宅完工实景"镜、能耗篇图2/图4/图16

### Type-Outro｜品牌收尾卡（固定模板）
- 定义：栏目收尾，LOGO+统一slogan"璀璨家的空气答案，懂空气，更懂家的尺度"
- 视觉规范：与Type-QA共用同一套深咖+暗金视觉语言，形成开场/收尾呼应
- 生成方式：不进AI视频，纯静态模板
- 参考镜头：能耗篇图16（本期变体："舒适不减 能耗更优"）

## 3. 视觉设计系统（把两种视觉语言合成一套）

现在最大的割裂感来源：Type-DataCard（设计感强、像信息图）和Type-Hook/Lifestyle（实景+字幕条）用的是两套完全不同的视觉语言，观众会觉得像"看了一半广告片，切到一半信息图PPT"。统一规则：

- **色板**：深咖 `#3B2F2C`／香槟金 `#B8952A`／雾白 `#F0EDE8`，全片统一，不引入这三色以外的强色（尤其避免图5账单卡里那种绿色数字，尽量替换成金色或中性色系）
- **字幕条与数据卡同源**：Type-Hook的字幕条也要套用Type-DataCard同款的"圆角卡片+金色细描边"框，而不是随手加的白字+阴影——让观众感知到"这是同一个视觉系统在讲故事"，不是字幕和信息图各干各的
- **字体**：中文思源宋体/黑体做标题，Arial做数字和英文（APF、AI等）
- **图标风格**：统一用细线条描边图标（如图6的温度计/遥控/空调图标），不要在同一支视频里混用不同粗细/风格的图标

## 4. 节奏与配比规则

一支30-45秒视频，按能耗篇/层高篇的密度，通常是7-9镜（不含固定的Type-QA开场与Type-Outro收尾）。配比规则：

1. **固定镜**：Type-QA ×1（开场）+ Type-Outro ×1（收尾），共2镜，不计入下面比例
2. **中间镜头配比**（以7镜为例）：
   - Type-DataCard：至少 2-3 镜（这是保科普感的底线，低于2镜这期就会显得"没科普感"）
   - Type-Product：1-2 镜
   - Type-Hook / Type-Lifestyle：合计不超过3镜
   - Type-UI：0-1镜（视本期是否涉及App/线控功能）
3. **强制规则——转折句必配数据卡**：VO口播里但凡出现"所以/因此/关键是/更重要的是/其实/差距在于"这类逻辑转折词，对应画面**必须**是Type-DataCard，不能继续用Type-Lifestyle空镜带过（这是能耗篇脚本里"更重要的是→APF值+AI省电"这个转折处理得好的地方，要固化成规则）
4. **连续同类镜头上限**：Type-Hook/Lifestyle最多连续2镜，之后必须切一个Type-DataCard或Type-Product，避免看起来像"家居图合集"
5. **首尾呼应**：Type-QA提出的问题，Type-Outro前最后一镜（通常是Type-DataCard或Type-Product）要给出可视化的"答案闭环"，比如能耗篇里APF/594元这张卡，就是对片头"费不费电"这个问题的视觉解答

## 5. 家居图库建设（一次性生产，长期复用）

不要每期重新生成家居图，建一个可复用素材池：

- **规格**：大宅/大平层/别墅客厅、餐厅、卧室、玄关各若干张，9:16，暖调自然光，红书高级感构图
- **必备元素**：隐藏式横向线性长条风口入镜（不同角度各留几张），符合合规红线（禁外露风口/独立基座/木栈道/展示台）
- **打标签存档**：按"空间类型｜时段(晨/午/暮)｜色温(冷/暖)｜是否带出风口"分类存入Eagle，脚本阶段按需调用，不用每期现生成
- **数量建议**：首批20-30张覆盖大部分场景需求，后续按新脚本缺口补充，而不是每期从零生成

## 6. Codex 输入输出规范

**输入**：本期脚本xlsx（镜号/时间/画面建议/VO口播/屏幕字幕）

**输出**：分镜规划表，每镜包含以下字段：

| 字段 | 说明 |
|---|---|
| 镜号 | 沿用脚本原编号 |
| 时间 | 沿用脚本 |
| 类型标签 | Type-QA / Hook / DataCard(D1或D2) / Product / UI / Lifestyle / Outro |
| 生成方式 | A官方素材 / B达人实拍 / C即梦图生视频 / D HyperFrames透明通道动效 |
| 视觉细化描述 | 具体构图、色板取用、卡片/图标样式、数据高亮方式；D2类需注明用2.1表哪种风格打法 |

出规划表后，先过一遍第4节的配比规则自检（DataCard数量是否够、转折句是否配对、有没有连续超2镜同类型），不满足就调整类型分配，再交付。

### 6.1 制作阶段划分与每镜产出版本规则

**三个阶段，不是一条直线，C类和D类是两条并行支线，不是先后关系：**

1. **分镜图/预览稿阶段**（脚本→分镜规划表→静态图）——本SOP当前主要覆盖的阶段
2. **视频渲染阶段**（分镜图确认、选定版本之后才进行）——C类走即梦图生视频；D类走HyperFrames生成透明通道动效视频。这两条线互不依赖：即梦只处理C类镜头，HyperFrames只处理D类镜头，不存在"即梦跑完视频后再触发HyperFrames"这种先后关系，HyperFrames渲染的触发条件是"这一镜的静态设计预览稿已经选定"，跟其他镜头是否已经生成视频无关
3. **剪映合成阶段**——各镜视频素材+透明动效层+产品特写+固定模板按顺序拼接

**每镜产出版本数，按"这一镜是否需要叠加UI/字幕/数据卡设计层"判断，不是按Type名称判断**（因为字幕条可能出现在Hook也可能出现在Lifestyle，不固定绑定某个Type标签）：

| 情况 | 产出版本 |
|---|---|
| 需要叠加设计层（带字幕条的实景镜头、Type-UI、DataCard-D1实景叠加卡） | 3版——2版纯素材/背景图（不带任何文字/UI/数据卡层，用于筛选场景构图）+ 1版在其中一版基础上完成对应UI/字幕/数据卡设计叠加的预览图 |
| 本身就是完整设计成品，没有"素材层"概念（DataCard-D2独立科普镜头） | 2版设计方案供筛选 |
| 官方素材/固定模板类（Type-Product、Type-QA、Type-Outro） | 不需要多版本AI生成，直接用官方素材/改字模板 |

## 8. 质检清单（品牌感/科普感/种草感/节奏感/爆款感）

- **品牌感**：Type-QA/Outro视觉是否统一、色板是否只用深咖/暗金/雾白三色
- **科普感**：Type-DataCard是否≥2镜、转折句是否都配了数据卡、透明通道动效是否清晰稳定（没有糊字变形）
- **种草感**：Type-Product是否给到具体可感知的数字（不是空泛的"省电"，而是"APF4.4/594元"这种具体锚点）
- **节奏感**：是否有连续超2镜同类型堆积、镜头时长是否和信息密度匹配（数据卡类可以稍长，纯氛围镜头别拖）
- **爆款感**：开场3秒（Type-QA→Type-Hook）是否有痛点/悬念钩子，不是平铺直叙进产品
