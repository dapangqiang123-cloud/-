# 《家的空气答案》第六期《多空间选型》成片制作提示词（v2 · 给 Codex / 即梦）

> 用途：复制整份给 Codex 执行。Codex 可调用即梦出图/出视频，也可自己写代码做叠层动效与成片合成。  
> 相对 v1（纯代码线稿信息图）的核心纠正：**主体必须是有完成度的商业级画面，禁止整片丑线稿；代码只做辅助动效。**

---

## 0. 一句话目标

做一条 **9:16 竖版、约 84 秒、无人出镜** 的璀璨中央空调品牌科普短视频：看起来像 **商业级社媒口碑讲解片**，用画面把「四种情况怎么选」讲清楚；信息可视化要高级、克制，但 **不能** 做成满屏咖色底 + 稀薄线框的「代码演示片」。

栏目：家的空气答案 · 第六期《多空间选型》  
品牌：海信璀璨中央空调（TRÉSOR）

---

## 1. 交付节奏（必须遵守）

1. **先做风格样片约 15 秒（无字或极少字）** → 给人确认风格后再铺完整 84 秒。  
2. 样片建议内容：挑最典型的 **Q1 客餐厅大空间送风**（或 Q2 多房间独立控制）做完整质感段落，能代表最终片的材质、光影、转场与叠层动效水平。  
3. 确认后再做全片；全片导出两版：`final_with_text.mp4`（含标题/花字）与 `textless_plate.mp4`（无文字底板，方便后期加字）。  
4. 另输出 `timing.json`（场景起止、花字出现时间），供配音对齐。不生成音频、不用 TTS、不烧录口播字幕。

## 2. 制作能力怎么用（综合即梦 + 代码）

### 2.1 即梦 / 生图 / 生视频负责「主体画面」
- 高端中国家庭客餐厅、卧室、全屋剖切/轴测、产品实景感、净化/新风氛围等 **有体积、材质、光影、空间层次** 的画面。  
- 静帧精致够用时：用 **推拉/平移 Ken Burns + 局部高亮 + 气流粒子 + 连线 + 图层揭开** 等代码叠层做成讲解动效。  
- 需要「场景自己活起来」（家具微动、窗帘、绕镜、气流在真实空间中流动）再用即梦/Seedance 等生视频。  
- 产品外观（尤其外机）**不得变形、改色、改结构**；有参考图时必须锁定参考。

### 2.2 代码负责「讲解层」，禁止喧宾夺主
- 允许：气流粒子、送风距离标尺、管路生长、房间点亮、数字滚动、扫描净化、章节色块转场、进度条。  
- **禁止**：整段用细线框户型代替真实空间；大标题卡翻页；静态海报缩放淡入；满屏光效；霓虹/赛博。  
- 线条与粒子只能 **辅助解释**，不能代替主体。

### 2.3 背景与版式
- **不要全程深咖底**。米白 `#F5F2ED` / 雾白 `#F0EDE8` 与深咖 `#3B2F2C` / `#433538` **交替穿插**：生活场景偏米白明亮；章节转场/收口可深咖；产品特写可用米白或浅景深实景。  
- 暗金 `#B8952A` 或 VI 暗金 `#D49879` 仅作数据与细线高亮，面积 ≤ 画面约 10%。  
- 全片禁用纯黑 `#000000`。  
- 样片阶段 **不要先加多余花字/大标题**（后期可加）；全片有字版再按时间轴加必要信息字。  
- 文字不要叠在产品素材脸上，放旁边。

## 3. 风格参考（只学感觉，不照搬）

- **Bloomberg Quicksight / Agio×Bloomberg**：学其「信息密度克制、段落节奏、图形解释与创意剪辑」，**不要**照搬满屏线框测标注版式，更不要做成咖色工程图。参考可看：https://www.weareagio.com/bloomberg  
- **商业级家电/空调科普社媒片**：真实或高质量拟真家居 + 准确产品 + 克制可视化；画面本身演绎知识，不是靠读字。  
- 可选动效节奏参考：https://www.youtube.com/watch?v=28j7CASh09E（干净信息图节拍；配色改璀璨，禁止蓝主色与竞品元素）。

## 4. 技术规格

- 画幅 **1080×1920**，**30fps**，总时长目标 **84.0s**（样片约 **15s**）。  
- H.264 MP4，yuv420p，+faststart；无音轨。  
- 工程建议：`config`（文案/色板/时间表）+ 分镜素材目录 + 渲染/合成脚本；可 `--preview`（如 540×960 / 15fps）、`--from/--to` 分段渲。  
- 【SLOT】素材位：有文件就用，缺失先用高质量生成画面顶上，并标注待替换；不要用黑色占位。  
- 渲染后 ffprobe 校验时长/分辨率/帧率；输出关键场景中点 PNG 供审核。

---

## 5. 硬性禁止

- 壁挂机、落地柜机、明装风管、暖气片的图形或实拍。  
- 室内出现外机（外机只在阳台/室外/产品展示合理位置）。  
- 竞品 logo；木栈道/展示台/独立基座；真实可辨人脸（人只用抽象远景或不出镜）；emoji；纯黑主调。  
- 室内出风口只画/只拍 **吊顶隐藏式横向线性长条风口**（极窄横缝，平齐天花）。  
- **不得自行添加脚本之外的数字、参数、功效表述**（尤其除醛率等；脚本没写就不要写）。  
- 试片/样片默认不加 Logo 角标（全片收口再出品牌落版）。

安全区（全片有字版）：上 220px、下 360px 不放关键文字；左右边距 72px。  
全局 UI（全片有字版）：左上「家的空气答案」、右上「第六期」；底栏 Q1–Q4 进度；右下 logo 或「璀璨 TRÉSOR」。样片可先不做这些字。

动效原则：缓入用 power3/expo 类；禁止弹跳 elastic/back；同时运动元素 ≤ 4；章节转场可用色块擦除约 0.5s（深咖↔橄榄↔米白轮换）。

## 7. 完整时间轴（84s · VO 只对齐，不渲染口播字幕）

### S0 0–4s 开篇
- 画面：高端住宅吊顶/客餐厅快切或缓推（米白明亮），建立「秋冬装修选中央空调」氛围；可用 【SLOT:s0_bg】。  
- 有字版：大标题「秋冬装修，中央空调怎么选？」+ 副标「选之前先看这四点」；01–04 点依次亮。  
- VO：秋冬装修，中央空调怎么选才适合你家？不同户型、不同需求，选之前先看这四点。

### S1 4–9s Q1 转场
- 「Q1」+「针对客餐厅大空间，该怎么选？」；标签「客餐厅一体 · 大空间」。色块擦除转场。

### S1b 9–17s 气流与空间纵深（样片优先做这段）
- **精致客餐厅一体实景/高完成度三维**，天花隐藏线性出风口；气流从客厅送向餐厅，均匀覆盖；「送风距离」可视化。  
- 14–17s：先表达「风送不远、局部冷热」再纠正为全域覆盖（可用对比，但主体仍要好看、可读）。  
- 花字（有字版）：「送风风量」「送风距离」。  
- VO：如果你家是客餐厅一体的大空间，匹数之外，更要看内机风量和送风距离，风送不远，只能局部冷热才是坑。

### S1c 17–22s C2艺境
- 【SLOT:c2_product】产品+客餐厅；旁侧「18m」滚动 + 超远送风示意。花字：「18m超远送风」。  
- VO：璀璨客餐厅中央空调C2艺境，18米超远送风，全空间均匀冷热，更适合这类大空间用户。

### S2 22–27s Q2 转场
- 「Q2」+「全屋都想装中央空调，该怎么选？」；三/四房依次亮起（在精致户型或生活场景上点亮，不是丑线框）。

### S2b 27–35s 一拖多与独立控制
- 一台外机连多房间；各房独立点亮；抽象旋钮/独立控制示意（**不显示具体温度数字**）。  
- 花字 31–35s：「产品品质 / 决定 / 生活舒适度」。  
- VO：如果你家多个房间都要装，先看各房间能不能独立控制。多空间多人群使用，产品的品质和稳定性将决定未来的生活舒适度。

### S2c 35–40s C3知境
- 【SLOT:c3_product】；一拖多管路动画。花字依次：「日系核心压缩机」→「冷媒散热」→「高温不宕机」。  
- VO：璀璨中央空调C3知境系列多联机，配置日系高品质压缩机，动力强劲，一台外机带多台内机，稳定运行，各屋按需开。

### S3 40–45s Q3 转场
- 「Q3」+「家里有老人孩子，该怎么选？」；新家装修感（家具/柜体），人用抽象圆点或不出现。

### S3b 45–54s 污染物被净化
- 室内空间中甲醛/细菌/异味粒子被净化扫描吸附消散；标注「甲醛」「PM2.5」「异味」。  
- 花字：「空气净化能力是关键」。  
- VO：如果你家有老人孩子，这时拥有空气净化能力的中央空调就更为必要，要能同时应对甲醛、PM2.5、异味等常见污染物。

### S3c 54–60s C3D
- 【SLOT:c3d_product】，可选 【SLOT:hinano_fx】；三层净化示意。花字：「Hi-nano Ultra健康模块」+「除醛|除菌|除异味」。  
- **画面不出现任何除醛率数字。**  
- VO：璀璨中央空调C3D系列，搭载Hi-nano Ultra健康模块，三重净化，能有效除醛、除菌、除异味。

### S4 60–65s Q4 转场
- 「Q4」+「秋冬季节易敏感怕憋闷，怎么选」；关窗、闷感（CO₂ 条只定性，不显示数值）。

### S4b 65–73s 新风换气
- 室外新鲜空气进入，闷感消散。花字：「持续新风换气很重要」。  
- VO：如果你家秋冬常关窗，重点就要看新风换气能力，能不能不开窗，也持续把室外新鲜空气送进来。

### S4c 73–78s Mini新风
- 【SLOT:mini_product】；「99%」与「350m³/h」滚动；三层过滤示意。花字：「母婴级舒适新风」。  
- VO：璀璨Mini新风系统，具备三层过滤能力，PM2.5净化效率高端99%，350m³/h超大新风量，快速置换室内空气。

### S5 78–84s 收口
- 四款产品依次：C2艺境 / C3知境 / C3D / Mini新风（【SLOT】），关键词：18m超远送风 / 日系核心压缩机 / 三重净化 / 350m³/h新风量。  
- 主句：不同空间，不同家庭，自然有不同答案。  
- 落版：璀璨中央空调 让每一种舒适，都选得恰到好处 + logo；末 0.5s 静止。  
- VO：不同空间，不同家庭，自然有不同答案。璀璨中央空调，让每一种舒适，都选得恰到好处。

## 9. 验收标准

### 15 秒样片
- 竖屏可播，约 15s，**无字或极少字**。  
- 一看就是商业级家居/产品科普，而不是线稿 PPT。  
- 米白与深咖有穿插；气流/讲解叠层服务知识点且不脏。  
- 能代表最终 84s 的质感上限。

### 全片 84s
- 1080×1920@30fps，时长准；有字版 + 无字版 + timing.json。  
- 四点选型叙事完整；参数不越界；禁止项全中。  
- 主体始终有材质与空间完成度，代码层只做增强。
