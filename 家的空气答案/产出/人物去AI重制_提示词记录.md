# 人物去 AI 重制提示词记录

日期：2026-09-18

## 执行范围

- 第三期：镜1（素材 v1、素材 v2、UI 设计版）、镜5（素材 v2）、镜6（素材 v1、素材 v2、UI 设计版），共 7 张。
- 第四期：镜1、镜3、镜4（各含素材 v1、素材 v2、UI 设计版），共 9 张。
- 只修改人物、服装与动作状态；已确认的空间、家具、隐藏式风口、产品线控器、淡白微蓝风效、科普 UI、中文文字与 9:16 构图必须保持。

## 全局人物与摄影约束

所有人物均为真实亚洲家庭成员或顾问，穿适合夏末初秋室内环境的轻薄棉、亚麻或薄针织单品，避免厚毛衣、厚外套、高领、冬装和明显叠穿。人物完全不看镜头，呈现 candid lifestyle photography、off-guard moment、unposed、unaware of camera 的纪实抓拍状态；不得出现模特姿态、T 台站姿、广告感夸张微笑或刻意表情管理。

动作必须正在发生，身体重心真实自然，手部动作有明确目的。表情克制，可专注、放松、若有所思或轻微自然微笑。保留真实亚洲人物的细微毛孔、肤色不均、轻微眼纹、自然法令纹、面部起伏和碎发，禁止过度磨皮、塑料皮肤、蜡像感、CGI 面部、网红精修脸和过度对称五官。

摄影遵循真实相机抓拍逻辑：35mm 或 50mm documentary photography、natural window light、shallow depth of field、subtle film grain、slight motion blur、occasional foreground occlusion、imperfect framing、真实景深和自然曝光。效果应像高端生活方式杂志摄影师进入真实住宅后的随手抓拍，不是广告棚拍、模特写真或 AI 人物展示图。

## 逐镜动作设计

### 第三期

- 镜1素材 v1：两位成年人正在餐桌旁比较装修/空调方案；一人用铅笔指向图纸，另一人顺势按住或翻动纸张，头部与视线都落在资料上。轻薄短袖或卷袖棉麻上衣、透气长裤，站姿重心不对称，像讨论过程中被抓拍。
- 镜1素材 v2：过肩视角，两人坐着或倚桌讨论方案；一人正翻页，另一人用手指沿平面图比划路线。保留前景遮挡和不完美构图。
- 镜1 UI 设计版：沿用镜1素材的真实讨论动作，只替换人物表现；必须原样保留 `风管机 VS 多联机` 与 `怎么选？`。
- 镜5素材 v2：只重制可见手臂、手部与袖口；改为轻薄棉麻卷袖或短袖，手指正在有目的地操作 C2 圆形线控器。其余场景、线控器、风口和风效不变。
- 镜6素材 v1：一家三口处于真实互动中；成年人正在递书、翻页或递杯子，孩子跟随画面内容或伸手接物。轻薄夏秋装、裸露前臂、无人看镜头。
- 镜6素材 v2：成年人正在给孩子指书中细节，孩子同时翻页或顺着手指看，动作有连续性。轻薄棉质上衣，表情自然专注。
- 镜6 UI 设计版：沿用家庭互动抓拍，只替换人物表现；必须保留 C3 矩形线控器、风效，以及 `三重净化`、`Hi-nano Ultra`、`除醛 除菌 除异味`。

### 第四期

- 镜1素材 v1：成年人正在拿着户型图边走边标记或将图纸转向餐厅确认尺度，身体处于一步移动或自然换重心状态；轻薄棉麻卷袖衬衫和垂感长裤。
- 镜1素材 v2：两位成年人坐在桌边共同核对户型图；一人以铅笔描路线，另一人按住纸边或翻页，目光都在图纸上。
- 镜1 UI 设计版：沿用核对户型图的纪实动作；必须原样保留 `50㎡客餐厅` 与 `一台够吗？`。
- 镜3素材 v1：近处人物正在翻书、移动杯子或整理桌面，远处人物正摆放物品/倒水/整理餐桌，两人都在具体动作中且不看镜头。
- 镜3素材 v2：保留前后景层次和真实空间距离，近处人物正在翻页，远处人物正完成家务动作；夏秋轻薄装、自然窗光。
- 镜3 UI 设计版：沿用前后景生活动作；必须保留淡白微蓝风效与 `冷量够 ≠ 全屋都舒服`。
- 镜4素材 v1：人物正用一根手指操作 C2 圆形线控器，身体处于自然迈步或换重心状态，视线只看线控器；轻薄短袖或卷袖棉麻上衣。
- 镜4素材 v2：人物从侧后方自然伸手操作线控器，手臂有目的、肩颈放松、非摆拍；保留隐藏式风口与淡白微蓝风效。
- 镜4 UI 设计版：沿用真实操作动作；必须保留 C2 圆形线控器、风口、风效，以及 `C2艺境`、`18m`、`超远送风`。

## 禁止项

厚毛衣、厚外套、高领冬装、商务正装、模特式正面站立、人物看镜头、商业标准微笑、夸张肢体、无目的手势、僵硬手指、额外人物、面部磨皮、蜡像皮肤、网红脸、CGI 人脸、棚拍打光、过度干净构图、改变室内风格、改变线控器或产品、改变 UI 文字、金色风效。
