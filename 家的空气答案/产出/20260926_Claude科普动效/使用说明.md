# 家的空气答案 · 第三期、第四期科普动效镜头

共 12 个镜头，风格是浅奶油底加深咖字加金色线稿，和 Codex 的 A/B 版实景图同一套调性。Codex 那套主要是静态的等轴实景图，这套是会动的线稿户型、气流和数字滚动，两套可以混着用。

先看根目录的 `总览_末帧.jpg`，再看两个 `串看.mp4`，一分钟就能过完。

## 每个镜头有 3 个文件

| 文件 | 用途 |
|---|---|
| `_完整版.mp4` | 自带奶油底，剪映里直接用 |
| `_合成预览.mp4` | 叠加类镜头的效果预览，底图借用了 Codex A 版的实景素材 |
| `_透明通道.mov` | 透明底，拖到剪映画中画轨道，叠在任意画面上 |
| `_末帧.jpg` | 最后一帧，方便挑选 |

叠加类镜头（第三期镜5、镜6，第四期镜7）最终要用透明通道版，叠在你选定的实景视频上。

## 版式安全区

顶部 0-180px 留给 Hisense/TRÉSOR 角标，底部 1540px 以下留给字幕，两处都没有放内容。

## 内容与合规

- **C2艺境：** 18m、1400m³/h、8600W、约50㎡，只用在 C2艺境 上。
- **C3知境：** 三重净化写的是"除醛、除菌、除异味"，没有写任何百分比。
- **温度标签：** 冷热不均和循环两镜里的温度都标注了"温度为示意"。
- **产品图：** 双产品收口和 8600W 两镜用的是项目 `产品素材` 里的官方外机图，只放在产品卡片上，没有合成进室内实景。

## 脚本里建议定稿前改的地方

1. **第三期镜6：** 口播是"除醛除**霾**除异味"，花字和品牌口径都是"除**菌**"，建议口播改成"除菌"。
2. **第三期 24-32s：** 口播里"多联机更能满足……"和"多联机就更合适"重复了，删掉一句。
3. **口播超时：** 第四期镜2 约70字、第三期镜5 约65字，按正常语速都要 14-16 秒，和时间轴对不上。
4. **备选说法未定：** 第三期镜1、第四期镜6 的括号里还有备选说法，需要选定一个。

## 不在这批里的

- 第三期镜1、第四期镜1：AI 实景，走生图、生视频流程。
- 两期的 LOGO 收尾，以及第四期镜8 的产品落版：用固定模板。

## 修改与重渲染

`制作文件/动效源码_可重渲染.zip` 是全部源码。改字、改数字、改时长只需要改 `shots/` 里对应的文件，然后运行 `python3 render.py <镜头名> full <输出名>`，需要 Playwright 和 ffmpeg。
