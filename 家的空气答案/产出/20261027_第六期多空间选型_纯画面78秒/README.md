## 时长微调

`python3 retime.py --duration 81.2 --output timing_81.2.json`

也可读取用户配音时长（仅探测，不生成或导出声音）：

`python3 retime.py --voiceover /绝对路径/配音.wav --output timing_vo.json`

按原始78秒时间边界等比缩放，再量化到30fps；最终总帧数等于目标秒数乘30的最近整数，各镜头首尾连续，最后停稳段同比缩放。该工具只修改时间计划，不会把未渲染的方案伪装成视频，也不会自动拉伸现有视频文件。进入成片制作后按新计划重渲染代码镜头并重做源片剪辑。
