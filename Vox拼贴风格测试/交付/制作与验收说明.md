# 璀璨《让空气，也有风景》

25秒横版品牌短片；璀璨 Mini 全热交换新风系统。1920×1080 / 30fps / H.264 / AAC 48kHz立体声。

成片：`璀璨_让空气也有风景_25秒_1080p.mp4`。
附 `璀璨_让空气也有风景_封面.jpg`、`六镜画面总览.jpg`、旁白SRT及生成用量CSV。
可编辑工程：上一级 `OpenFilm工程/film.html`。每个镜头是独立页面，文字与摄影图层可编辑；转场、旁白、配乐、音效分轨。旁白字幕另附SRT，成片中的文字是设计文案，不是满屏字幕。

## 风格拆解与落地

参考作品：[Mixed Media Explainer: Vox Creative x JP Morgan / Sara Afridi](https://www.behance.net/gallery/215058845/Mixed-Media-Explainer-Vox-Creative-x-JP-Morgan)。

- 摄影山体、森林、实物切片组成微缩空间，保留照片细节。
- 纸白底、细地图线、路径与实物尺度变化承担解释和转场。
- 前后景分别运动，摄影片层在同一空间中重组。
- 本片将其色彩改为温润米白、深咖、香槟金和克制橄榄绿。
- 窗框、山脊、路径、家居与产品串起“新风让家的空气换个风景”的视觉隐喻。山野为创意意象，不代表产品可把特定山林空气直接送入住宅。

原参考视频和声音未进入成片。本片没有使用其他品牌标识或未核实的性能数字。

## 打开与修改

双击 `../打开OpenFilm工程.command`，或在OpenFilm里打开 `OpenFilm工程` 文件夹。该文件夹中的 `film.html` 是时间线；`scene1.html` 至 `scene6.html` 为镜头，`scene.js` 为动画，`style.css` 为视觉样式。

本地重新导出：在工程目录运行已安装的 OpenFilm CLI：

```sh
node '/Applications/OpenFilm.app/Contents/Resources/app.asar.unpacked/node_modules/openfilm/bin/openfilm.mjs' render --out '../交付/璀璨_让空气也有风景_25秒_1080p.mp4' --fps 30 --workers 2 --samples 3 --shutter 0.4
```

保留了全部源图与生成记录。`制作文件`中的Python脚本用于重建源动画；直接改工程后不应随意运行重建脚本，以免覆盖手工调整。
