## 可继续编辑

HyperFrames工程在`可编辑工程/index.html`，包含全部合成素材、透明ProRes人物视频、本地字体、GSAP和独立音乐。可以调整文字、位置、节奏、颜色与镜头路径；不是剪映原生草稿。

在工程目录可运行`npm run check`和`npm run render -- --output ../成片/修改版.mp4`。当前固定HyperFrames 0.8.185。ProRes透明视频在浏览器编辑预览里由框架提供代理，正式渲染读取原始透明素材。整套工程与素材目录应一起保留。

`制作文件/build.py`可重建同一HTML；`key_video.py`为纯本地抠像；`run_once.py`已执行并设有再次运行阻断，不要更改生成次数记录或换提交ID重生。
